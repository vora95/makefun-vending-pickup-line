A vending machine's one-line pickup line for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" — a single line, 200 characters at most, spoken by the machine itself to a passing human, built on its own world of coils, buttons and dropped snacks.

## Run it

```sh
OUTPUT_DIR=./output node main.ts
```

The program is fully deterministic — no clock, no randomness, no network, no input — and writes the entry to `entry.txt` inside the output directory.
